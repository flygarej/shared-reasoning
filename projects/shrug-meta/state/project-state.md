# project-state.md

## Project
**SHRUG Meta** — Shared Reasoning methodology

## Objective

Study, refine and validate the Shared Reasoning methodology itself rather
than a technical domain.

## Accepted Scope

This project concerns:

- evolution of the methodology;
- cross-model observations;
- knowledge representation;
- maintenance practices;
- future automation.

## Project Structure

- `state/` — accepted project knowledge and chronology.
- `domain/` — compact conceptual model.
- `observations/` — project-local observations that have not yet been
  promoted into accepted knowledge.

Observations are intentionally lightweight. They provide an incubation
stage for ideas, recurring behaviours and empirical findings before they
are promoted into project state, generators, anchors or boundaries.

## Accepted Observations

- Shared Reasoning has been successfully applied to multiple long-running
  technical projects.
- GBA appears to reduce contextual clutter while preserving
  reconstruction quality.
- Different LLMs reconstruct similar knowledge while exhibiting different
  collaboration styles.
- Fresh collaborators requested missing project state rather than
  inventing one.

## Working Models

- GBA is a compact conceptual representation reconstructed through
  constrained inference.
- Human or externally grounded observations remain the epistemic
  linchpin.
- Future agent execution may provide grounded observations if their
  verification scope is explicit.

## Community

**SHRUG — Shared Reasoning User Group** is the informal community that
shares observations and helps evolve the methodology through evidence.

## Open Questions

- Representation of per-model observations.
- Verification provenance.
- Safe automation.
- LLM–LLM collaboration.

## Next Milestone

Digest initial observations into the first stable generators.
