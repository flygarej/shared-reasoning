# observations.md

# Purpose

This directory records project-local observations that may improve the
Shared Reasoning methodology but have not yet been promoted into accepted
project knowledge.

Observations may originate from:

- experiments;
- collaboration sessions;
- cross-model comparisons;
- workflow experience;
- reconstruction failures;
- successful practices.

## Promotion

An observation may eventually become:

- project-state;
- a generator;
- an anchor;
- a boundary;
- or remain an observation if additional evidence is needed.

The objective is to preserve useful evidence without prematurely turning
it into accepted knowledge.
